# PaperRead CLI 1.4.7-cli.6 翻譯流程實測

日期：2026-10-20。測試使用自製兩頁英文學術樣本，含公式、數值、表格、否定語意與適用範圍限制，不使用個人文獻。

## 已完成的改進

- AGY 同一次回答逐步產生唯讀預覽；Codex 讀取 CLI 回答事件，可見時間受 CLI 事件粒度影響。完整結果仍走原本解析、漏頁、公式、格式、術語與繁中處理。
- 相同來源、提示與設定的單段重譯，在排隊及執行期間共用一個任務。完成、取消或來源改變後，重新提交仍是新任務。
- 最多兩篇同時處理，共用原設定的模型請求上限，自動最多四個；設定一個時仍只執行一個。未加入單段或閱讀頁優先，未調整各篇分批順序。
- 快取同頁重複字元的正規化結果，保留相同座標與連字映射。
- 每篇 job.json 記錄排隊、準備、模型等待、首段及本機處理時間，不儲存提示詞原文。預覽不進入正式正文、筆記及匯出。

## 回歸與發布門檻

- Python 全套：418 通過、327 個 subtests 通過；新增排程／預覽／重複提交測試均通過。
- JavaScript：153 通過。
- 隔離 HTTP 驗證：生成時正式區塊仍為零、預覽已出現；完成後兩頁成功、14 個正式區塊、預覽清空；僅一個回傳請求用量紀錄。
- Windows 讀取可靠性：壓力測試曾出現原子替換期間的暫時讀取拒絕，已增加有限次本機讀取重試；持續拒絕或毀損 JSON 仍會明確報錯。新增相關測試後全套通過。
- 編碼與安全：預覽 HTML 轉義、截斷 JSON 不當作完整區塊、Codex 同時排空 stdout/stderr、大輸入不死鎖、取消不遺留上限名額。
- 桌面打包、安裝、本機版本、資料完整性與 macOS CI 另於發布時核對。
- 視覺驗證：使用者提供的完成後截圖可確認正文及公式渲染；PDF 對照曾因測試頁誤配打包煙霧測試 PDF 而不一致，已換成與譯文相符的兩頁 PDF 並重新抽取真實座標。Computer Use 自動審核仍無法可靠辨識 Chrome 網址，因此不宣稱已完成自動介面操作。
